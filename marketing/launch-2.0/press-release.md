# NumPad 2.0 Turns the iPhone Keyboard Into a Calculator That Answers Before You Finish Typing

### Solo developer's numeric-keypad app adds live math, Siri support, and Liquid Glass themes — one-time pricing, no subscription, and a keyboard that ships with zero analytics

**CITY — July 7, 2026** — More Voltage today released NumPad 2.0, the largest update to
its numeric-keypad keyboard for iPhone and iPad. NumPad replaces the stock keyboard's
cramped number row with a full calculator-style keypad available in every app that
accepts text — and with 2.0, the keypad now computes as the user types. Finish an
expression like "84.50*1.18" in any text field and the answer appears in a floating chip
before the "=" key is ever pressed.

The same offline math engine now answers Siri. Three zero-setup shortcuts — "Calculate
with NumPad," "Convert units with NumPad," and "Calculate a tip with NumPad" — work the
moment the app is installed, with no configuration and no network connection required.

NumPad 2.0 also adds two new key packs (Units & Conversion, with a live offline
converter, and Cooking & Baking, with fraction keys and a cups-to-milliliters converter),
a rebuilt drag-and-drop editor that lets Pro users construct their own keyboard around
the fixed keypad, Liquid Glass theme materials on iOS 26, and a Kiosk-sized keyboard
height for iPads mounted at checkout counters, front desks, and counting stations.

"A keyboard is the most intimate software on a phone, so NumPad is built like a small
sharp tool," said James Ryan, the app's sole developer. "The keyboard extension
contains no analytics code at all — not disabled, absent. And nothing is rented: $2.99
buys the app, packs are $1.99 once, Pro is $11.99 once, and Family Sharing is on for
every purchase."

The base app includes the numeric keypad, Math keys, 15 themes, text snippets, and
clipboard history. Long-press gestures reach a two-step tax-and-tip calculator, clipboard
history, snippets, and the unit converter; every calculation lands on a running result
tape. On wide iPads, those tools open as a side panel beside the user's work rather than
covering it.

NumPad 2.0 is available now on the App Store for iPhone and iPad running iOS 16 or
later: https://apps.apple.com/us/app/numpad-your-number-keyboard/id1072547160

Press kit: https://morevoltage.com/

**About More Voltage** — More Voltage is an independent one-person iOS studio. NumPad,
its numeric-keypad keyboard for iPhone and iPad, has been developed and maintained by
the same sole developer since its first release in 2016.

### What's new in 2.0

- Live Math Preview: expressions compute in a floating chip as you type, before "="
- Siri / Shortcuts / Spotlight: three zero-setup intents (calculate, convert units, tip), fully offline
- Two new packs: Units & Conversion (live offline converter) and Cooking & Baking (fractions, cups→ml)
- Rebuilt Custom Keyboard editor: drag-and-drop key library, live preview, left/right-handed toggle, date/time token keys (Pro)
- Liquid Glass themes on iOS 26, with a matched dark twin (17 themes total)
- Bigger iPad keyboard heights, including a Kiosk preset for point-of-sale and front-desk iPads (Pro)
- Interactive first-run walkthrough; Family Sharing enabled on all purchases

### Core features (all versions)

- Full 3×4 numeric keypad as a system keyboard, in any app that accepts text
- Long-press "%": two-step tax + tip calculator (tip computed on the pre-tax amount)
- Long-press "0": clipboard history · Long-press ".": snippets · Long-press "=": unit converter
- Running result tape for every calculation
- iPad: overlays dock as a side panel on wide screens, pointer-hover keys, drag-and-drop into the host app

### Privacy claims (verifiable in the shipped binary)

- The keyboard extension contains **no analytics SDK** — no keystroke logging, no tracking code present
- Full Access is optional; it enables only clipboard history, haptics, and key-click sounds, all on-device
- All math (calculator, converters, Siri intents) runs fully offline
- iOS itself prevents third-party keyboards from operating in secure password fields
